# drip-drop
Wardrobe Management and Outfit AI assistant

# Setup

This project is managed using UV. To get started, follow these steps:

1. Clone the repository:
   ```
   git clone https://github.com/your-username/drip-drop.git
   ```

2. Navigate to the project directory:
   ```
   cd drip-drop
   ```

3. Create a .env file with the following content:
   ```
   SUPABASE_URL=https://url.com
   SUPABASE_KEY=secret_key
   ```

3. Run the application:
   ```
   uv run app/main.py
   ```
